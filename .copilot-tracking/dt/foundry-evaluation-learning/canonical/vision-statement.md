# Foundry evaluation learning vision

## Vision Statement

We aim to give consultants, delivery engineers, and solution architects practical Microsoft Foundry evaluation skills through a guided lab that connects quality priorities, built-in checks, generated rubrics, repeated evaluation, and evidence-based improvement.

### Why This Matters

Learners should be able to use evaluation early during development and explain its value and limits in customer solutions. The lab teaches tooling through hands-on tasks, not customer delivery role-play.

The target is less than two hours after required provisioning pre-work. Learners need basic Foundry knowledge, but no previous workshop track or Python authoring. Supplied scripts remain visible for engineers.

These are requester-approved goals, not measured learning outcomes. The selected journey is Run Understand Customize. Its timing, integrated execution, cost, and learning effectiveness remain unverified.
