# Foundry evaluation learning problem

## Problem Statement

The limited practical evaluation experience assumed for the intended learners is producing an avoidable effort to connect quality requirements with repeatable evidence for consultants, delivery engineers, and solution architects. How might we do guided hands-on Foundry evaluation learning so that we can provide practical skills to define criteria, assess changes, and explain quality evidence and its limits?

### Evidence and limits

This statement follows the canonical problem-framing template. The requester approved the learning gap as a working baseline. Limited learner experience is a design assumption, not a population-wide finding.

Two requester-supplied practitioner excerpts inform the research. No independent learner observation, measured training benefit, or direct customer validation supports a broader causal claim. Method 3 and Method 5 were closed for progression with these limits, not as fully validated research.
